# BottomNav

The app's four-tab navigation: Trips · Explore · Tools · Profile.

`surface-card`, `radius-xl` top corners, `shadow-nav`, height `nav-height` (84px incl. home-indicator padding). Each tab is an `a` with a 24px stroke icon over a `micro` label. Active tab: `accent`, weight 600, `aria-current="page"`; others `ink-muted`, 500. During an active trip the Trips tab opens on Today. No badges or counters. The consumer provides the active tab.
